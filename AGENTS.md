# AGENTS.md

The guide for an AI agent working in this repository or a fork of it is [CLAUDE.md](CLAUDE.md): the map of the
repository, the commands, the workflow from a song to a film, the conventions, and the rules with their reasons.
Read that file in full before changing anything. It is kept in one place so the two never disagree.

The short version: `npm run setup`, `npm run hello`, `npm run starter -- SONG.mp3`, then `docs/story.md`.
Before pushing: `npm test`.
